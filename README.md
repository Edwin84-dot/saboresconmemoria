# Sabores con Memoria

Sitio web estático para presentar la propuesta editorial y visual de "Sabores con Memoria".

## Archivos principales
- `index.html`: estructura principal del sitio.
- `style.css`: estilos y diseño visual.
- `script.js`: interacciones y contenido dinámico.
- `assets/`: imágenes y recursos gráficos.
- `audio/`: relatos en audio.

## Cómo abrirlo
Abre `index.html` en el navegador o usa un servidor local sencillo como:

```bash
python -m http.server 8000
```

Y luego visita `http://localhost:8000`.
